RailInsight — documentation technique
======================================

**RailInsight** est une webapp Streamlit d'analyse de la régularité des TGV
(jeu de données open data SNCF). Cette documentation présente l'architecture
du package ``railinsight`` (chargement des données, analyses, visualisations,
gestion des erreurs et des logs) générée automatiquement à partir des
docstrings du code source.

Pour l'installation et l'utilisation de l'application, voir le `README
<https://github.com/JulienCRB/IADATA_700_SNCF/blob/main/README.md>`_ du dépôt.
